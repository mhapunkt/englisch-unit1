# Vokabeltest – Unit 1 bis Part C

Interaktiver Multiple-Choice-Test auf Grundlage der abfotografierten Vokabelliste bis einschließlich Part C. Jeder Durchgang enthält 20 neu gemischte Fragen: 12 schwierige Schreibweisen und Wendungen, 6 Bedeutungen mit thematisch nahen Antworten und 2 Präpositions- oder Grammatikfallen.

## Lokal starten

```bash
npm install
npm run dev
```

## GitHub Pages

Das Projekt ist eine statische Vite-App. `npm run build` erzeugt den Inhalt in `dist/`.
