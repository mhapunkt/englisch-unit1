# Vokabeltest – Unit 1 bis Part B

Interaktiver Multiple-Choice-Test auf Grundlage der abfotografierten Vokabelliste. Jeder Durchgang enthält 20 neu gemischte Fragen: 12 zur Schreibweise, 6 zu Wendungen und 2 zu Präpositionen. Die falschen Antworten greifen typische Schreib- und Grammatikfehler auf.

## Lokal starten

```bash
npm install
npm run dev
```

## GitHub Pages

Das Projekt ist eine statische Vite-App. `npm run build` erzeugt den Inhalt in `dist/`.

## Prüfung

`npm test` prüft den Fragenpool und die Zusammensetzung der Runden.
