# Vokabeltest – Unit 1 bis Part B

Interaktiver Multiple-Choice-Test auf Grundlage der abfotografierten Vokabelliste. Jeder Durchgang enthält 20 neu gemischte Fragen aus Übersetzungen, Schreibweisen und Präpositionen.

## Lokal starten

```bash
npm install
npm run dev
```

## GitHub Pages

Das Projekt ist eine statische Vite-App. `npm run build` erzeugt den Inhalt in `dist/`.
